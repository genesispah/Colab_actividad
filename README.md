# 📊 Análisis de Altura de Alumnos Destacados (Pandas)

## 📌 Descripción del proyecto

Proyecto de análisis de datos utilizando Python y Pandas para estudiar la distribución de alturas de alumnos destacados en Argentina y países limítrofes.

El objetivo es explorar y comparar las alturas de estudiantes en posiciones similares dentro de rankings académicos, aplicando técnicas de limpieza, transformación y visualización de datos.

---

## 🛠️ Herramientas utilizadas

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

---

## 🗂️ Dataset

El dataset contiene información sobre alumnos destacados y presenta las siguientes características:

* `id_pais`: identificador numérico del país
* `0 - 9`: alturas (en cm) de alumnos ordenados por ranking

  * 0 = primer puesto
  * 9 = décimo puesto
* `escuela`: nombre de la escuela

---

## 🔄 Proceso de análisis

### 1. Exploración de datos

* Revisión de estructura del dataset
* Identificación de tipos de datos
* Análisis inicial de distribución

---

### 2. Limpieza de datos

* Manejo de valores nulos
* Verificación de consistencia en alturas
* Corrección de posibles anomalías

---

### 3. Transformación y modelado

* Reorganización del dataset para facilitar el análisis
* Conversión a formato adecuado para comparación por ranking
* Creación de métricas estadísticas

---

### 4. Análisis de datos

* Comparación de alturas entre países
* Análisis por posiciones en el ranking
* Cálculo de medias, medianas y dispersión

---

### 5. Visualización

* Gráficos de distribución de alturas
* Comparaciones entre países
* Representación de tendencias por ranking

---

## 📊 Resultados

* Identificación de diferencias de altura entre países
* Análisis de patrones en posiciones de ranking
* Visualización clara de la distribución de alturas

---

## 🎯 Conclusión

El análisis permite comprender cómo varían las alturas de alumnos destacados entre distintos países y posiciones en el ranking, utilizando herramientas de análisis de datos en Python.
